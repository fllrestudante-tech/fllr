# Papers

Reservado. Vazio hoje -- nenhum paper acadêmico foi formalmente
incorporado ao Feature Registry ainda (`type: "paper"` no
`registry/research-objects.json`).

Quando um Research Object `type: "paper"` precisar de um resumo mais
longo do que cabe em `description`/`references`, o arquivo correspondente
entra aqui (`research/papers/<paper-id>.md`), linkado de volta pelo
`references` do Research Object.
